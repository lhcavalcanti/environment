# macOS software I use

All of these are currently installed on this Mac in `/Applications`.

| Software       | What I use it for                                                                  | Install                                                                                                                                                                                                                                                    | Local app path                     |
| -------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| Raycast        | Keyboard launcher, app switching, snippets, extensions, and quick actions.         | [raycast.com](https://www.raycast.com/) — click **Download**, move it to Applications, then launch it and set your preferred hotkey.                                                                                                                       | `/Applications/Raycast.app`        |
| Shottr         | Fast screenshots, annotations, measurements, and quick image editing.              | [shottr.cc](https://shottr.cc/) — download it from the homepage, move it to Applications, then grant Screen Recording / Accessibility permissions if prompted.                                                                                             | `/Applications/Shottr.app`         |
| Amphetamine    | Keep the Mac awake when I do not want sleep or display sleep to interrupt work.    | [Mac App Store](https://apps.apple.com/us/app/amphetamine/id937984704) — install from the App Store, then launch it and enable the menu bar item / triggers you want.                                                                                      | `/Applications/Amphetamine.app`    |
| iTerm2         | Terminal emulator for shell work, profiles, panes, tabs, and keyboard shortcuts.  | `brew install --cask iterm2` or download it from [iterm2.com](https://iterm2.com/) and move it to Applications.                                                                                                                                        | `/Applications/iTerm.app`          |
| Memory Clean 2 | Menu bar memory cleaner to free inactive memory after heavy apps or games.         | [FIPLAB Memory Clean 2](https://fiplab.com/apps/memory-clean-for-mac) — download from the official page, move it to Applications, then configure manual or automatic cleaning thresholds.                                                                  | `/Applications/Memory Clean 2.app` |
